# Counter App

A simple and interactive **Counter App** built using **HTML, CSS, and JavaScript**.

This project allows users to increment a counter, save the current count, and display previously saved entries. It is a beginner-friendly project created to practice **JavaScript DOM manipulation, event handling, functions, and basic frontend development**.

## Live Preview

The application provides a simple interface where you can:

- Increment the counter
- Save the current count
- View previously saved entries
- Reset the counter by refreshing the page

## Features

- Simple and responsive user interface
- Increment button to increase the counter
- Save button to store the current count
- Displays previous counter entries
- Background image for a visually appealing design
- Uses JavaScript to dynamically update the webpage

## Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and layout
- **JavaScript** – Functionality and DOM manipulation
